- **Behavior.** [output-folder.ts](../../src/main/output-folder.ts) `createOutputFolderOpener` stats the configured folder:

  - the missing known default is created with a non-recursive `mkdir`, only inside an existing parent folder, and then opened;

An older version is historical only and adds just its missing verification records. package.json keeps its earlier rule, advancing to a newer recorded stable version and never moving back, independently of the pointers; pre-releases stay historical only. A missing, unreadable or malformed baseline, including one carrying a pre-release tag, stops before any write with the remedy `pnpm site:manifest generate vX.Y.Z`. ## Notification switch replaces the native bridge — 2026-09-21

Plan 019 was first implemented as a Node-API bridge to macOS `UserNotifications` (preserved on `wip/019-native-notification-bridge`): a permission state machine, launch-time guidance dialog, status display in Settings and a build/packaging pipeline that compiled a `.node` on every build. Review found the bridge inverted the failure direction. `AppTray.show` was gated on a status that starts as `unknown`, so a bridge that failed to load dropped every notification — and because the gate also suppressed `Notification.show()`, it suppressed the authorization request Electron makes from inside that call.
