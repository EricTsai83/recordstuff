2026-09-28（Asia/Taipei），乾淨的 tag 原始碼 `7b44eb2e8c99fe6a6cbd953ee3eefee929cb57cb` 通過 `pnpm check`（68 個測試檔、1,140 個測試、TypeScript 檢查及正式建置）。`pnpm start:app` 在 macOS 26.6.2（25G83）、arm64 建置、自簽並驗證 `dist/mac-arm64/RecordStuff.app`。本機 bundle 保留上次已發布的 package 版本 1.0.0；CI 依 tag 寫入 1.1.0。自 1.0.0 起封裝設定（electron-builder 檔案、App 圖示、DMG 背景與版面）未變更；新增的選單列圖示屬於既有 `extraResources` 篩選範圍內的 App 資源，因此本機未執行 `pnpm dist:mac`。

未變更設定。腳本關閉測試素材並正常退出 RecordStuff，程序檢查確認兩者均已結束。既有擷取權限可用；未測首次授權。
