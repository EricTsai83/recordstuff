# 023 — 用全域快捷鍵開啟設定

[English](023-settings-shortcut.md) | [繁體中文](023-settings-shortcut.zh-TW.md)

狀態：尚未開始；本次僅建立計畫。優先順序：緊接 020，排在 021、022 前；既有計畫編號不變。建立：2026-09-23。

## 問題與目標

目前原生 computer use 驗收經常需要維護者先從選單列開啟設定，才能繼續測試。新增使用者也能使用的全域快捷鍵，讓其他 App 在前景時，仍能開啟並聚焦 RecordStuff 設定，讓 computer use 不需人工協助即可進入面板。這裡指的是 App 的偏好設定，不是 macOS「系統設定」。

[index.ts](../src/main/index.ts) 既有的 `openSettings` action 已呼叫 [settings-window.ts](../src/main/settings-window.ts) 的 `SettingsWindow.show()`，建立或聚焦單一面板。沿用這條路徑。只在選單顯示快捷鍵，或只有面板已取得焦點時才能使用，都不符合本計畫目標。

## 預期行為

- 新增專用全域快捷鍵，暫定 `CommandOrControl+Alt+,`（macOS：⌘⌥,）；實作時透過原生驗收確認組合再定案。一般 ⌘, 留給前景 App 使用。本計畫不要求設定快捷鍵本身可自訂。
- App ready 後註冊，退出時只解除這項註冊。註冊所有權與狀態獨立於 [hotkey.ts](../src/main/hotkey.ts) 的錄影快捷鍵；關閉或更換錄影快捷鍵不得讓設定入口失效。
- 開啟、還原已最小化的面板並取得焦點；重複按鍵不建立額外視窗，也不切換成關閉。關閉後可直接用快捷鍵再次開啟，不需重啟 App。
- 開啟設定不開始或停止錄影。錄影中仍可開啟，原有偏好鎖定規則不變。
- 在選單列的「設定」項目旁顯示組合，並提供雙語文件。註冊回傳失敗或拋錯時，保留選單入口、記錄失敗並顯示本地化的不可用說明；不得顯示成正常可用，也不在每次刷新時重複通知。
- 明確處理與 020 自訂錄影快捷鍵的衝突。新選擇若等同設定快捷鍵，拒絕儲存並提供本地化原因。既有儲存值若已使用同一組合，保留該值與錄影行為，讓設定快捷鍵呈現不可用，並說明可從選單開啟設定、更換錄影快捷鍵來恢復。變更後重新協調註冊，不中斷進行中的錄影。
- 自訂快捷鍵錄入期間，依需要暫停設定快捷鍵註冊，避免攔截正在錄入的按鍵。提交、取消、失焦、逾時、關窗或 renderer 失敗後皆須恢復。錄入設定保留組合時應顯示驗證訊息，不得意外觸發動作。保留 020 的錄影快捷鍵暫停行為。

## 實作與驗證

- [ ] 新增共用設定快捷鍵常數與明確的註冊／狀態生命週期；沿用既有 `openSettings` action，避免以 `unregisterAll` 影響錄影註冊。
- [ ] 視需要補齊聚焦／還原行為、選單提示、本地化失敗回饋及錄影快捷鍵衝突驗證。以正規化及平台等價組合比較，不只比較原始字串，並涵蓋既有偏好值。
- [ ] 加入針對性的測試：註冊成功／失敗／拋錯與清理、錄影快捷鍵獨立性、衝突恢復、錄入暫停／恢復、單一視窗重開／聚焦／還原，以及錄影狀態與鎖定不變。
- [ ] 執行 `pnpm check` 與 `git diff --check`。
- [ ] 依[原生 computer use 驗收 skill](../.agents/skills/astra-acceptance-with-computer-use/SKILL.md)，操作由 `pnpm start:app` 啟動的 bundle。退出或重建前檢查錄影狀態，不中斷使用者的錄影。
- [ ] 從設定已關閉、其他 App 在前景的狀態開始，由 computer use 發送真實全域按鍵，觀察設定面板可見且取得焦點，以鍵盤操作控制項，關閉後再次用快捷鍵開啟。不得以維護者點擊、直接 IPC、fixture 視窗或測試專用入口替代此項驗收。
- [ ] 驗證重複按鍵、最小化／背景面板恢復、錄影快捷鍵停用／自訂，以及錄入提交／取消／失焦／逾時／關窗後的恢復；涵蓋英文與繁中 UI。
- [ ] 啟動測試錄影，以快捷鍵開啟設定，確認控制項鎖定且錄影未中斷，再停止、儲存與播放。還原測試修改的偏好，停止並儲存自己啟動的錄影。
- [ ] 驗證註冊被拒與既有快捷鍵衝突／恢復。可用受控測試確定覆蓋錯誤分支，但須與 OS 層級的原生證據分開記錄。遇到權限或 computer use 限制須如實記錄，人工協助的流程不得稱為無人值守。
- [ ] 更新驗收 skill、相關工具與桌面設計的雙語文件，改用此入口。在[驗證紀錄](../docs/zh-TW/verification/README.md)留下實際原生操作、結果、證據與未測項目。

## 完成條件與範圍

完成條件是 computer use 能從其他前景 App 自行開啟並操作真正的設定面板，不需請維護者先開啟。快捷鍵仍以 App 正在執行、組合可註冊且 computer use 環境能送出按鍵為前提；本計畫不承諾自動處理 OS 權限對話框。

不包含設定視覺重設、macOS 系統設定自動化、發布、commit、push 或 PR。020 的既有驗收狀態維持如實記錄；新增本計畫不代表其待驗項目完成。完成後將永久行為與證據留在文件，依[計畫完成規則](README.zh-TW.md#完成計畫)收尾。
