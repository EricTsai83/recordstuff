# 071 — 錄影檔分頁的資料夾與搜尋

## 目標與邊界

錄影檔分頁只列出輸出資料夾第一層的影片，依新到舊排列，無法整理也無法搜尋。維護者於 2026-10-09 要求 App 能整理自己的錄影檔，並讓使用者更容易找到它們。標籤經評估後延後：標籤需要自己的儲存位置（App 資料、sidecar 檔或僅限 macOS 的 Finder 標籤），每一種都會在常見情況下遺失；兩套重疊的分類方式對 menu bar 錄影工具也是負擔。

資料夾是輸出資料夾裡真實的子資料夾，只有一層，因此 Finder 與 App 永遠一致，不需要另存資料，重裝、同步或「清除本機 App 資料」後資料夾都還在。維護者於 2026-10-09 接受只有一層：樹狀結構在只放得下兩張卡片的視窗裡需要側欄與麵包屑，輸出資料夾是 `~/Movies` 或桌面時可能掃描無關的深層目錄，也會出現資料夾移進自己子層的情況。

不在範圍內：標籤、多層資料夾、把新錄影存到指定資料夾、在視窗開啟之間記住所選資料夾或搜尋字，以及搜尋檔名以外的內容。錄影、擷取與寫檔都不改。

## 規格

- **列出。** 列出輸出資料夾的直接子資料夾及其中第一層的影片；排除隱藏資料夾、名稱以副檔名結尾者（`iMovie Library.imovielibrary`、`Foo.app` 等套件）與符號連結。有可見檔案但沒有影片的資料夾不顯示（`~/Movies` 裡無關的資料夾）；完全空的資料夾會顯示，新建的資料夾才看得到。更深層的影片不列出，也不會被動到。無法讀取的子資料夾不顯示並寫入 log。
- **監看。** 視窗開著時以 recursive 方式監看；只有資料夾本身或直接子資料夾裡列出的檔名，以及資料夾本身裡可能是子資料夾的名稱有事件時，才重新列出。更深層的變更等下次取得焦點。
- **資料夾列。** 全部、未分類（資料夾本身）與各資料夾，附數量，最後是「新增資料夾」。選取的資料夾提供「重新命名資料夾…」與「刪除資料夾」。選取狀態只存在頁面中。
- **移動。** 卡片選單新增「移到 ▸」（未分類與所在資料夾以外的各資料夾）；把卡片拖到資料夾列上的資料夾也會移動。移動絕不覆蓋其他檔案（沿用改名的先連結再刪除，或沒有硬連結時先獨占保留名稱）；名稱已被占用時會說明。長度與縮圖一併帶過去。
- **建立／改名／刪除。** 名稱比照檔名檢查，且不能以點開頭或以副檔名結尾。改名絕不取代其他資料夾：已存在的名稱會被拒絕，只改大小寫可以。只有沒有可見檔案的資料夾才提供刪除，並移到垃圾桶；其中仍在等待 Undo 的錄影會先移到垃圾桶。等待期間改名的資料夾，其中錄影的 Undo 仍有效。
- **搜尋。** 分頁標題列的搜尋框以檔名（不分大小寫）篩選所選資料夾的卡片；選「全部」時涵蓋所有資料夾。沒有符合結果與資料夾是空的會各自說明。
- **進入。** 「顯示最後一次錄影」與存檔通知仍會把該錄影帶到畫面中：頁面清除搜尋並選取「全部」。
- **安全。** main 只解析目前列出的 id 與資料夾；頁面從不傳送路徑。

## 實作順序

- [x] 1. Library：子資料夾列出、recursive 監看過濾、共用的不覆蓋移動、`move`、`createFolder`、`renameFolder`、`removeFolder`，以真實暫存資料夾寫模組測試。
- [x] 2. View 與 IPC：`LibraryView.folders`、`LibraryItemView.folder`、選項型別檢查、model／window 路由與 main 接線，附 model 與 window 測試。
- [x] 3. 頁面：資料夾列、資料夾選單與對話框、「移到」、拖放到資料夾、搜尋、空狀態與進入時重設，附頁面測試；英文與繁體中文文案。
- [x] 4. 文件：[桌面設計](../docs/zh-TW/system-design/desktop.md)、函式目錄及其翻譯。

## 驗證與限制

Settings 控制項、persistence 與 IPC：受影響的單元測試、`pnpm typecheck`，以及在最終建置上跑一次 `pnpm acceptance:regression`；`git diff --check`。不需要錄影 smoke：沒有改到擷取或寫檔路徑。

背景無法證明：卡片的原生拖曳（`webContents.startDrag`）是否會以 drop 事件送回同一頁面，以及 recursive 監看大型輸出資料夾的 CPU（`pnpm measure:cpu`，需桌面回合；監看只在視窗開著時存在）。除非維護者要求桌面回合，兩者都列為未驗證。

結案時把長期規格留在系統設計，把證據與限制記在驗證紀錄，更新兩份索引並移除本計畫檔。
