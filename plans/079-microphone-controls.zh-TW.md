# 079 — 麥克風控制：音量表、尋找裝置、錄影中切換

[English](079-microphone-controls.md) | [繁體中文](079-microphone-controls.zh-TW.md)

狀態：已規劃；尚未開始。建立：2026-10-17，依維護者在 078 桌面回合的要求（「可以放在之後做」）。優先順序：由維護者排序；除非提前，否則排在 075 之後。硬性相依：074 的麥克風（已結案），以及 078 的 HAL 擷取與裝置檢查（已結案，[紀錄](../docs/zh-TW/verification/history-2026-10.md#plan-078-結案--2026-10-17)）。依[計畫索引](README.zh-TW.md)按順序執行步驟。

## 目標與範圍

讓使用者不必錄一段測試就能在設定中檢查與管理麥克風：看所選的輸入是否聽得到自己、找到剛連接的輸入，並決定錄影中能否更換麥克風。成功的標準是：「輸入裝置」選擇器旁有隨所選輸入的聲音變動的輸入音量表；裝置清單會跟著連接變化，並有「搜尋裝置」按鈕；以及維護者對錄影中切換的決定，若採納則實作。

不在範圍內：語音處理、增益或降噪控制（074 以單位增益錄製原始麥克風）、中斷的麥克風自動換成另一支（維護者已於 2026-10-17 否決：收回的是同一個裝置），以及 Windows 實機回合（只由 CI 驗證）。

## 目前狀態

- **無法檢查輸入。**設定會列出輸入裝置並儲存選擇；在播放錄影之前，沒有任何東西顯示它是否收得到聲音。078 的回合中，維護者要求一個音量表來檢查麥克風。
- **過時的清單。**清單由一個短暫的擷取程序在設定視窗被啟用或開關開啟時讀取，從不自行更新。設定視窗在前景時連接的 FreeClip 2 耳機，要等視窗再次被啟用才出現，而且 macOS 列出它的麥克風還要等一下（見[錄影流程](../docs/zh-TW/system-design/recording.md#音訊)）。
- **錄影中無法切換。**一個 session 沿用建立時選定的麥克風；錄影中做的選擇套用到下一段錄影。引擎已經能關閉 HAL 單元並依 UID 開啟另一個裝置（078 的重新連接），所以切換主要是 main 到引擎的串接，以及音軌中的接縫。

## 步驟

### 1. 決定行為

- [ ] **D1 音量表。**建議：在「輸入裝置」選擇器下方放一條水平音量條，在「麥克風」開關開啟、且於待命狀態開著設定時顯示；由引擎的列舉程序讀取所選輸入（macOS 用 HAL，Windows 用 WASAPI），每秒約 20 次送出峰值與 RMS；視窗關閉或失去焦點、錄影開始，以及缺少權限時停止（改顯示卡片的指引）。替代方案：聆聽幾秒的「測試」按鈕；renderer 以 `getUserMedia` 做的音量表（Chromium 中的另一條擷取路徑與權限提示）。依據：不需要錄影，而且音量表用的是引擎自己的擷取，因此顯示的就是錄影會聽到的聲音。
- [ ] **D2 尋找裝置。**建議：清單自行跟著連接變化（CoreAudio 的 `kAudioHardwarePropertyDevices` listener、Windows 上的 `IMMNotificationClient`，在設定開啟期間於列舉程序中執行），再加上選擇器旁立即重新列舉的「搜尋裝置」按鈕作為備援。替代方案：只有按鈕；設定開啟期間輪詢。
- [ ] **D3 錄影中切換。**由維護者決定使用者能否在錄影中更換輸入裝置。若採納，建議：錄影中選擇器保持可用，引擎關閉目前的單元並開啟新裝置，空隙由對齊器留為靜音，log 與儲存的紀錄寫出兩個裝置，新裝置開啟失敗時保留舊裝置。否則：選擇器標示更改將套用到下一段錄影。

### 2. 實作

- [ ] 依 D1 的音量表：一個引擎命令，在列舉程序中從所選輸入串流音量，main 轉送給設定的 renderer；音量條放在「錄影設定」分頁的「音訊」區塊，使用正式元件，字串有兩種語言，並以 `role="meter"`、音量作為其值。
- [ ] 依 D2 的裝置變化：列舉程序中的 listener、不需啟用視窗就會重新整理的清單，以及帶忙碌狀態的按鈕。
- [ ] 若採納 D3 的切換：main 送給執行中引擎的 `microphone` 訊息、讀取執行緒依新 UID 重新開啟，以及接縫與紀錄。

### 3. 驗證與文件

- [ ] 音量計算與清單更新的單元測試；音量表、按鈕與（若實作）錄影中選擇器的背景 UI 案例；Windows 由 CI 檢查。
- [ ] 在簽署 bundle 上進行一輪桌面驗證：音量表隨說話變動、在沒有聲音的輸入上保持不動；設定在前景時連接與斷開藍牙耳機，不必啟用視窗就會出現與消失；開著設定與音量表時的 CPU；若實作，錄影中切換。
- [ ] 把結果記錄在[錄影流程](../docs/zh-TW/system-design/recording.md)、[桌面](../docs/zh-TW/system-design/desktop.md)與驗證紀錄，並附上翻譯。

## 完成與驗證邊界

每個步驟都完成，或由維護者接受其結果，即算完成。引擎與 UI 的修改依[測試政策](../docs/zh-TW/testing.md#依行為選擇測試)；桌面回合遵守[桌面交接](../docs/zh-TW/testing.md#測試前確認桌面交接)。撰寫本 plan 只需檢查連結、中英文一致與 `git diff --check`。
