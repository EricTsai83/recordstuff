# 013 macOS Installation Experience

[English](013-macos-installation-experience.md) | [繁體中文](013-macos-installation-experience.zh-TW.md)

Status: Source changes implemented and locally verified on 2026-09-19; local acceptance before tagging and the 0.1.2 release remain. Updated: 2026-09-19. Do not replace published v0.1.0 or v0.1.1 assets.

## Outcome

A simple DMG presents RecordStuff → Applications without any bundled installation/help documents. Users can find first-launch, manual-update, and uninstall guidance before downloading. This does not depend on release automation (011) or a website (012).

## Done in source (0.1.2)

Durable descriptions live in [release automation](../docs/system-design/releases.md), [tooling](../docs/system-design/tooling.md), [design decisions](../docs/system-design/decisions.md) and the [installation guide](../resources/INSTALL.md); local evidence is in [0.1.2 verification](../docs/verification/releases/0.1.2.md).

- The DMG contains only `RecordStuff.app` and the `/Applications` link over a generated arrow background; no documents in any format. The release gate (`assertDmgContents`) fails on any other visible root entry.
- Release notes carry concise install, Open Anyway, permission/relaunch, manual-update and removal guidance with commit-pinned links to the bilingual guide.
- The guide documents manual update (same identity and path; settings retained) and removal (Trash; recordings, settings and logs remain; optional cleanup listed; nothing deleted automatically).
- package.json is 0.1.2; the local candidate build passed `pnpm dist:mac`, the candidate gate, and a Finder layout check.

## Reference and acceptance

T3 Code's [current official packaging configuration](https://github.com/pingdotgg/t3code/blob/main/scripts/build-desktop-artifact.ts) was checked on 2026-09-15: its DMG contents list only the App and /Applications link, plus a themed background. This project's implementation matches that shape; the arrow background is generated by `pnpm icons` rather than a hand-drawn asset.

Acceptance: the published 0.1.2 DMG contains no installation/help documents, the installation path is obvious, help remains accessible, and update/removal instructions reflect actual behavior. Existing releases remain unchanged. No automatic updater, Apple certification, other-platform work, or Finder notification-focus fix is included.

Coordinate notification fixes with [014](014-finder-notification-focus.md); app update feasibility is tracked separately in deferred [015](015-app-update-assessment.md). Ejecting a DMG is not uninstalling the app. Any temporary test backup should have a recorded purpose and be cleaned up after verification and settings restoration, without touching user recordings.
