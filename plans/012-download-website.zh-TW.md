# 012 官方網站與 DMG 下載

[English](012-download-website.md) | [繁體中文](012-download-website.zh-TW.md)

狀態：依使用者要求列為已規劃；可開始實作。更新：2026-09-19。本次僅寫計畫，未實作或部署網站。

## 目標與依賴

建立 RecordStuff 英文／繁體中文官方網站，介紹產品、提供醒目的 DMG 直接下載入口，並承載安裝、操作、更新及移除指引。安裝檔本身不附說明文件（0.1.2 已交付；見[發布自動化](../docs/zh-TW/system-design/releases.md)與[安裝指南](../resources/INSTALL.zh-TW.md)）。公開下載宣稱須符合已發布的 release metadata。不依賴 App 更新器（015）或自訂網域。

## 內容與導覽

- 首頁：簡潔說明用途（將主螢幕與系統音訊錄成 MP4）、真實截圖或短示範、主要功能及明顯 macOS 下載按鈕。說明選單列操作與本機儲存，不宣稱未驗行為。
- 下載區：已驗版本、架構、檔名、大小、發布日期、DMG 直接連結、SHA256SUMS 與發行說明。初版僅提供 macOS Apple silicon／arm64；舊版連到 GitHub Releases。不放假的 Windows／Linux／Intel 按鈕，也不以瀏覽器平台偵測隱藏可用選擇。
- 使用說明：拖入 Applications、自簽／「仍要打開」、螢幕／系統音訊權限與重啟、錄影及語言設定、手動替換更新、結束後移到垃圾桶，以及另列保留的設定／log／錄影資料。不把說明檔附進 DMG。
- 支援：已知限制（Finder 未置前修正前持續揭露）、已驗平台邊界、原始碼、問題回報，以及符合實作的隱私／儲存說明。GitHub 公開發行說明維持英文，官網與使用說明保留雙語。

## 工作

1. 實作時選擇靜態 hosting 與可用官方網址，GitHub Pages 僅為候選，尚未指定供應商。確認成本及部署方式；不含購買網域。規劃桌面／手機版面、可讀字體、鍵盤操作、語言切換及明確下載狀態。
2. GitHub Releases 作為唯一安裝檔來源。主要下載按鈕直接連到已驗 DMG，另提供 Release 頁入口。維護小型已驗 release manifest（版本、tag／來源、架構、URL、大小、雜湊與發布日期），或於建置時取已確認 metadata。不猜 asset 路徑、不把過期資訊標成最新，不強制引入執行時 API。
3. 記錄新版維護流程：發布及驗證新產物後，更新網站版本資訊、checksum／說明，核連結並部署；與已實作的 [發布自動化](../docs/zh-TW/system-design/releases.md) 協調此步驟。除非明確提供，排除草稿與 prerelease。metadata 失敗時保留清楚標示的最後已驗版本，或連到 Releases 且不宣稱最新；不可出現壞掉的下載按鈕。
4. 建立首頁／下載／說明頁或等效清楚區段，英／繁中一致。使用已移除私人內容的真實產品視覺素材。安裝指引適合沒有開發工具的使用者，不宣稱免安全提示、Apple 公證或自動更新。
5. 依執行授權部署。驗證 HTTPS、公開可讀、桌面／手機版面、鍵盤焦點、語言導覽、原始碼／支援／說明連結，以及循網站下載的實際產物。比對已發布 SHA256SUMS，記錄瀏覽器／quarantine／安裝結果或適用的既有驗證證據；按鈕可點不等於下載通過。
6. 記錄 hosting／專案網址、部署／更新指令、版本資訊維護方式至設計／工具文件、驗證紀錄及翻譯。執行授權下將真實網址加入雙語 README、GitHub repository About 與發行說明的 help 連結。網站失效時仍可使用 GitHub 下載入口。

## 驗收與範圍

官方公開網址正常載入，直接下載按鈕取得所標示的已驗 DMG，版本資訊／checksum 一致，雙語指引可用。沒有 placeholder 宣稱或壞連結。網站連到目前版本的 DMG、SHA256SUMS 與指南，每次公開新 tag 後更新。

不要求帳號、後端、付款、分析追蹤、安裝檔鏡像、購買網域或 App 更新器。T3 Code 的[下載頁](https://t3.codes/download)作為實作時查看的設計參考，不要求照抄版面或基礎設施。
