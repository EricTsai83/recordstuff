## 已安裝候選版檢查

使用者確認英文預設、切換繁中、結束／重開後保留，以及錄影／音訊播放正常。新檔 `2026-09-15 00-33-17.mp4` 對應安裝候選版 log：15.208933 秒、14,458,868 bytes、1920×1080 H.264、48 kHz 雙聲道 AAC；音訊平均 −25.8 dBFS、峰值 −7.9 dBFS。ffprobe 完整解碼通過，共 1,157 個音訊／影像 frame。FFmpeg 加上 `-fps_mode passthrough -enc_time_base:v 1:1000000` 完整解碼通過；預設 null 輸出 timebase 曾產生重複 output-DTS 警告，並非解碼器錯誤。

通知點擊 log 指向同一新檔，Finder 已選取該檔。**使用者觀察到 Finder 沒有跳到最前景。** `src/main/tray.test.ts` 以 mock 驗證延後呼叫 `shell.showItemInFolder`，未驗證 macOS 前景視窗。此限制已列入發行說明，不能宣稱焦點檢查通過。
