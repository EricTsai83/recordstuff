# Plans

每個計畫一個檔案，檔名 `NNN-slug.md`，編號是穩定識別；實際執行順序以本頁依賴為準。開始一個計畫前先在這裡把狀態改成「進行中」，做完改成「已完成」並填日期；計畫內容有變就直接改該檔，不另開版本。
