## 本機候選建置

在開發用 Mac（macOS 26、arm64、Node 24.21.0、pnpm 10.33.4、Electron 44.3、electron-builder 26.15.3）執行 `pnpm dist:mac`，以固定身分 `01B373511530BBF287CA35E54C10A5F017AAD637` 簽署，驗證九個 bundle 身分與 designated requirement 後打包 DMG。`node scripts/release.mts candidate v0.1.2 dist/local` 通過：唯讀掛載、可見根目錄恰為 `Applications` 與 `RecordStuff.app`、`/Applications` 連結、App 版本 0.1.2、arm64 與 App 簽章檢查。

- 檔案：`RecordStuff-0.1.2-arm64-selfsigned.dmg`
- 大小：126,059,078 bytes
- SHA-256：`7599a20bbf76c82e0e03379283e51a5fb77cfbe52b3fd3a12feeb74cc002723a`
- app.asar SHA-256：`07a537ed2b0433a6c0937796115dc97911fd803aa0994185f73b621bca683acc`

這些雜湊識別的是尚未提交的工作樹在本機的建置，其記錄的 source commit 仍是前一個 `d690a9c`。它們不是發布 bytes：CI 會從已提交的 0.1.2 原始碼重新建置，發布紀錄將取代這些數值。

隱藏的根目錄項目為 `.DS_Store`、`.VolumeIcon.icns` 與 `.background.tiff`，都是一般 Finder 版面檔；閘門現在拒絕其他任何隱藏項目以及任何隱藏資料夾或符號連結，指南或文件無法藏在隱藏位置或隱藏資料夾內通過。此變更後已在同一份 DMG 重跑閘門並通過。

## 自動化檢查

`pnpm check`（型別檢查、Vitest、建置）與 `git diff --check` 結果記錄於本次變更的最終實作報告。發布測試新增 `assertDmgContents`（只接受 App、Applications 連結與 Finder 版面檔；拒絕可見指南、多餘檔案、缺少 App、空根目錄，以及 `.INSTALL.md`、`.help/`、含指南的 `.background.tiff` 目錄等隱藏文件或資料夾；測試使用真實暫存目錄），以及發行說明必須包含「仍要打開」、權限、手動更新、移除與兩份指南連結。
