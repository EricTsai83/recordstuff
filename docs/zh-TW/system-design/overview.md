# 產品總覽

[English](../../system-design/overview.md) | [繁體中文](overview.md)

RecordStuff 在 macOS 選單列提供一個錄影按鈕：點一下錄下主螢幕與系統播放的聲音，再點一下停止，輸出可以直接開啟的 MP4。使用者不需要開專案、選編碼器或操作一般主視窗。

## 產品功能

| 功能 | 使用者行為與結果 | 設計所在 |
| --- | --- | --- |
| 開始／停止 | 左鍵切換；啟動及存檔期間忽略重複點擊 | [錄製管線](recording.md) |
| 主螢幕與系統音訊 | 每次開始選目前主螢幕；找不到對應來源時使用第一個來源；沒有可用音軌即失敗 | [架構](architecture.md) |
| 錄製狀態 | 待命圖示、錄製圖示與 macOS `REC`、啟動／儲存中的 `…` | [桌面功能](desktop.md) |
| 品質設定 | 精省／標準／高品質；1080p／1440p／4K／原尺寸；30／60 fps | [錄製管線](recording.md) |
| 儲存位置 | 預設 `~/Movies/RecordStuff`，可選其他資料夾並保存 | [桌面功能](desktop.md) |
| 存檔與定位 | 本地時間命名，停止後通知；可開輸出資料夾或顯示最後錄影 | [錄製管線](recording.md) |
| 權限引導 | 引導開系統設定；缺權限時提供重新啟動 | [桌面功能](desktop.md) |
| 失敗與退出 | 明確回報錯誤；盡力保留已寫入部分；錄製中結束先收尾 | [錄製管線](recording.md) |
| 語言 | 英文預設，選單可切繁體中文並保存；錄製中也可切換 | [桌面功能](desktop.md) |
| 診斷 | 所有狀態可從選單顯示 log | [桌面功能](desktop.md) |

預設品質是「標準、原尺寸、30 fps」。系統音訊固定要求 AAC 256 kbps，不提供麥克風錄音與音訊品質選單。音訊軌存在不代表來源正在發聲；目前會偵測缺少／已結束音軌，不會偵測每一段是否靜音。

## 平台與交付範圍

Electron 是可用於 Windows、Linux、macOS 的框架；RecordStuff 因設備限制，只驗證過 macOS 版本，具體環境是 Apple M1 Pro／macOS 26／Electron 44.3。框架跨平台不等於錄影、系統音訊或安裝流程在所有平台都通過。

現有程式保留 Windows 系統匣分支（ICO 素材、首次啟動提示），但未實機驗證，也沒有設定 Windows 打包目標；Linux 沒有專用打包／錄製驗證。macOS 程式有 Darwin 22（macOS 13）最低版本檢查，這只是程式門檻，不能視為已測遍 macOS 13 以上版本。Intel Mac 也未驗證，目前已驗的安裝產物是 arm64。

目標交付是可下載的 macOS 自簽 DMG：收件者不需 Node、pnpm、FFmpeg 或編譯工具。安裝到 Applications，完成系統允許開啟與錄影授權後即可操作。Apple 認證／公證、App Store、Windows／Linux 驗收不是交付條件。未公證 App 首次開啟可能需要手動安全例外，不能承諾免提示；見 [Apple 說明](https://support.apple.com/102445)。

## 資料與產品邊界

錄影與設定留在本機；目前沒有登入、雲端儲存、上傳服務、遙測、錄影庫、編輯器或自動更新。App 本身不提供遠端錄製 API。開發版的自動錄製環境變數在打包版被忽略。

目前也沒有區域／視窗選擇、全域快捷鍵、暫停續錄、分段檔、FFmpeg 修復、休眠或拔螢幕的專門事件處理。這些不列入本次交付的待辦。將來若有具體需求，再建立小範圍計畫。

## 品質原則

1. 正確性：畫面、音訊、檔案及圖示狀態要可信；失敗不得當成成功。
2. 整潔：模組責任明確，不為未排程的功能建立框架。
3. 韌性：資源有釋放路徑，故障時盡力保留媒體並留下診斷。
4. 效能：用量測決定是否需要優化，不把編碼要求值當成成品保證。
