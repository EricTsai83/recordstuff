## 發布後已安裝 App 的更新檢查

2026-10-03 維護者回覆「好了」後，Claude 以 1.0.0 與 1.1.1 原始碼（這兩個 tag 的 `src/main/app/updates.ts`）的更新解析器讀取線上 feed 與 GitHub latest release：兩版都把 `https://record.ericts.com/release.json` 與 GitHub release 解析為 1.2.0、判定較新，`fetchVersion` 也回傳 1.2.0。`/Applications/RecordStuff.app` 安裝的是 1.0.0，不是 1.1.1；先備份 `settings.json`，並把 `updates.lastAttempt` 往前調一天，讓每日一次的啟動檢查到期，啟動後 log 記錄 `start: RecordStuff 1.0.0`、既有擷取權限，並在啟動 0.4 秒後記錄 `updates: available; remote 1.2.0`。之後正常結束，沒有殘留程序，備份的 `settings.json` 逐位元組還原（SHA-256 不變）。1.0.0 儲存這次嘗試時，刪掉了它不認得的 `countdown` 與 `countdownSound` 欄位：執行比 1.1.0 更舊的 App 會把它們重設為預設值，這裡已由還原復原。沒有打開顯示結果的「設定 → 一般」（App 不會為此發通知或跳視窗），因此未觀察其文字；1.1.1 只以其原始碼解析器檢查。
