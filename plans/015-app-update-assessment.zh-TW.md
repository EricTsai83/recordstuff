# 015 App 更新機制評估

[English](015-app-update-assessment.md) | [繁體中文](015-app-update-assessment.zh-TW.md)

狀態：延後的決策選項，尚未排入實作。更新：2026-09-15。

## 現況與邊界

RecordStuff 沒有 App 內更新檢查或自動更新器。手動替換見[安裝指南](../resources/INSTALL.zh-TW.md)；tag 觸發的發布（[發布自動化](../docs/zh-TW/system-design/releases.md)）產生 release，不會更新使用者已安裝的 App。詢問更新機制不等於選定自動安裝政策。首版交付與安裝介面整理不依賴此評估。

## 啟動評估時的工作

1. 比較維持手動下載、使用者主動檢查更新並連到 Release 頁、完整自動更新器。說明實際使用價值與維護成本，不預設必須完整自動化。
2. 查核當前 Electron／updater 對固定自簽 macOS 身分、產物格式／feed metadata 及 Gatekeeper 的要求。先證明可行，再承諾透明更新；Apple 認證維持既有範圍外。
3. 提出更新時機與使用者控制：不可中斷錄影，安裝／重啟需明確意圖，處理離線、錯誤與未完成下載，驗證可信來源及檔案完整性，保留設定／錄影，拒絕非預期降版或錯誤架構。評估替換失敗的恢復方式。
4. 記錄決策與取捨。選定實作後，以具體實作／驗證計畫及相依關係取代此評估。宣稱更新器可用前，必須驗證真實舊版至新版更新、中斷下載恢復、錄影中的延後更新。

## 完成條件

留下具可行性證據的選擇與明確實作邊界。本次規劃不加入 updater 依賴、背景輪詢、遙測、新簽章身分或靜默安裝。
