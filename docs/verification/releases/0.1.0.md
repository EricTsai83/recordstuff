The new `2026-09-15 00-33-17.mp4` matches the installed candidate's log: 15.208933 s, 14,458,868 bytes, 1920×1080 H.264, 48 kHz/two-channel AAC; mean audio −25.8 dBFS, peak −7.9 dBFS. Full ffprobe frame decoding passed (1,157 audio/video frames). FFmpeg full decode passed with `-fps_mode passthrough -enc_time_base:v 1:1000000`; its default null-output timebase had generated duplicate output-DTS warnings, which are not decoder errors.

Notification click logged the same new file and selected it in Finder. **The user observed that Finder did not come to the front.** `src/main/tray.test.ts` tests a deferred `shell.showItemInFolder` request using a mock, not macOS foreground state. This limitation is disclosed in the release notes; it is not a full focus pass.
